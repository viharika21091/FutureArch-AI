# 🏗️ FutureArch AI

### Intelligent Software Architecture Recommendation & Evolution

FutureArch AI is a Python-based application designed to support software architecture evaluation and growth prediction through an interactive Streamlit interface.

## ✨ Features

- Architecture evaluation and scoring
- Architecture recommendation support
- Growth prediction
- Growth-level classification
- Interactive web interface powered by Streamlit
- Data-driven architecture analysis

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- CSV datasets

## 📁 Project Structure

```text
FutureArch_AI/
├── app.py
├── architecture_engine.py
├── growth_model.py
├── requirements.txt
└── data/
    └── architecture_data.csv
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/viharika21091/FutureArch-AI.git
cd FutureArch-AI
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to use the application.
